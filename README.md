# DiraTrack

מערכת מקומית למעקב אחר פרויקט דירה בישראל, מהזכייה ועד למסירה.

## התחלה מהירה

דרישות: Node.js 22 ומעלה, npm 10 ומעלה ו־Docker Desktop.

```bash
cp .env.example .env
npm install
npm run db:up
npm run db:migrate
npm run dev
```

האתר עולה ב־http://localhost:3000 וה־Research Worker פועל כתהליך נפרד.

## מחקר חי

המערכת מחוברת ל־**שבעה מקורות**:

### מקורות אוטומטיים (יוזמים חיפוש חיצוני)
- **אתר אסיה סיירוס** (יזם) - חיפוש אוטומטי דרך API הציבורי של WordPress. לפני שליחת נתוני הפרויקט, הממשק דורש אישור מפורש. כל תוצאה נשמרת עם כתובת המקור ומסומנת `דורש בדיקה` ואינה משנה עובדות בפרויקט באופן אוטומטי.
- **אתר עיריית יהוד־מונוסון** (עירוני) - חיפוש אוטומטי דרך API הציבורי של WordPress. דורש אישור מפורש לפני שליחת נתונים חיצונית. במקרה של חסימה (403/429) המערכת עוברת אוטומטית לפעולה ידנית.

### מקורות ידניים (הנחיות לחיפוש)
- **דירה בהנחה** (רשמי) - המערכת מציגה הנחיות לחיפוש ידני באתר הרשמי עם מספר ההגרלה. האתר דורש אינטראקציה (CAPTCHA) ולכן אין אוטומציה מלאה.
- **רשות מקרקעי ישראל** (רשמי) - המערכת מציגה הנחיות לחיפוש ידני לפי מספר מכרז, מגרש, גוש/חלקה או מספר פרויקט דיור. האתר הרשמי דורש אינטראקציה ידנית.
- **מינהל התכנון** (רשמי) - המערכת מציגה הנחיות לחיפוש ידני לפי מספר תוכנית, גוש/חלקה או מספר בקשה להיתר באתר המידע התכנוני הרשמי.
- **הוועדה המקומית יהוד־מונוסון** (עירוני) - המערכת מציגה הנחיות לחיפוש ידני לפי מספר תוכנית, בקשה להיתר, גוש/חלקה או מגרש באתר הוועדה המקומית.

### מקורות נוספים
- **מסמכים שהמשתמש העלה** - מסמכים מקומיים שהמשתמש מוסיף ישירות למערכת.

## בדיקות

```bash
# בדיקות יחידה
npm test

# הקמת מסד הנתונים לבדיקות
npm run test:db:migrate

# בדיקות E2E
npm run test:e2e

# בדיקות E2E במצב אינטראקטיבי
npm run test:e2e:ui

# דוח בדיקות
npm run test:e2e:report

# ניקוי מסד נתונים לבדיקות (עם הגנה)
npm run test:db:reset
```

**הערה חשובה**: בדיקות ה־E2E משתמשות במסד נתונים נפרד (`diratrack_test`) ולא משפיעות על מסד הנתונים של הפיתוח. המערכת כוללת הגנה שמונעת ניקוי של מסד נתונים שאינו מסד בדיקות.
